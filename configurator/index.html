FC COMMANDER Layout Configurator

Build a layout.ini for your FCCS without connecting to it.

This page works offline and never talks to your FCCS directly — browsers block a secure page from calling the device's plain-HTTP address. Build your layout here, download it, then paste it into the Layout file box on the device portal at http://192.168.4.1 (join the FC COMMANDER_xxxxxx Wi-Fi first). If you are already on the device portal you can edit everything there live instead.

Display

Function Select

layout.ini

Applying it

  1. Join the FCCS Wi-Fi (SSID FC COMMANDER_xxxxxx, password is the device MAC address).
  2. Open http://192.168.4.1.
  3. Paste the file into Layout file and press Apply to device.
